### 6. Evitar construir Γ completo (64 valores) en cada paso → contracción directa
Γ^λ_{μν}u^μv^ν = ½ g^{λα} [ (u·∂)g_{αν} v^ν + (v·∂)g_{αμ} u^μ − u^μ v^ν ∂_α g_{μν} ]

```julia
@inline function _metric_derivatives(st::AbstractSpacetime, x::SVector{4,T}) where {T}
    D  = Dual{ChristoffelTag,T,4}
    xd = SVector{4,D}(ntuple(i -> D(x[i], Partials(ntuple(j -> T(i == j), Val(4)))), Val(4)))
    return partials.(metric(st, xd)), metric_inverse(st, x)
end

@inline _directional(∂g, u) = map(p -> p[1]*u[1] + p[2]*u[2] + p[3]*u[3] + p[4]*u[4], ∂g)

@inline function _contract(∂g, ginv::SMatrix{4,4,T}, u::SVector{4,T}, v::SVector{4,T}) where {T}
    Du = _directional(∂g, u)
    Dv = _directional(∂g, v)
    w  = SVector{4,T}(ntuple(α -> u' * map(p -> p[α], ∂g) * v, Val(4)))
    return ginv * (T(0.5) * (Du * v + Dv * u - w))
end

function geodesic_equations_Vacuum(u::SVector{8,T}, p, t) where {T}
    x = SVector{4,T}(u[1], u[2], u[3], u[4])
    k = SVector{4,T}(u[5], u[6], u[7], u[8])
    ∂g, ginv = _metric_derivatives(p.spacetime, x)
    return vcat(k, -_contract(∂g, ginv, k, k))
end

function parallel_transport_equations_Vacuum(u::SVector{16,T}, p, t) where {T}
    x  = SVector{4,T}(u[1],  u[2],  u[3],  u[4])
    k  = SVector{4,T}(u[5],  u[6],  u[7],  u[8])
    ex = SVector{4,T}(u[9],  u[10], u[11], u[12])
    ey = SVector{4,T}(u[13], u[14], u[15], u[16])
    ∂g, ginv = _metric_derivatives(p.spacetime, x)
    return vcat(k, -_contract(∂g, ginv, k, k), -_contract(∂g, ginv, k, ex), -_contract(∂g, ginv, k, ey))
end
```

### 9. Unificar `_Ensemble_Problem` (duplicado) con `rhs(...)`
Mover los tipos de ecuaciones a `src/propagate/propagate_types.jl` (hoy vacío).
```julia
struct GeodesicEquationsVacuum          <: AbstractEquationSet end
struct ParallelTransportEquationsVacuum <: AbstractEquationSet end
rhs(::GeodesicEquationsVacuum)          = geodesic_equations_Vacuum
rhs(::ParallelTransportEquationsVacuum) = parallel_transport_equations_Vacuum

function Ensemble_Problem(cfg::Configuration{N,T}, initial_data::Matrix{T}) where {N,T}
    N == state_length(cfg.equations) || throw(DimensionMismatch("$(cfg.equations) needs N=$(state_length(cfg.equations)), got $N"))
    size(initial_data, 1) == N       || throw(DimensionMismatch("each column must have length $N"))
    numtype(cfg.spacetime) === T     || throw(ArgumentError("spacetime and u0 must share precision $T"))
    p         = IntegrationParameters(cfg.spacetime)
    prob      = SciMLBase.ODEProblem{false}(rhs(cfg.equations), cfg.u0, cfg.tspan, p)
    prob_func = (prob, ctx) -> SciMLBase.remake(prob; u0 = SVector{N,T}(view(initial_data, :, ctx.sim_id)))
    return SciMLBase.EnsembleProblem(prob; prob_func, safetycopy = false)
end
```
`prob_func(prob, ctx)` es correcto para SciMLBase ≥ 3.50 (instalada). Versiones viejas usan `(prob, i, repeat)`.

## 🧪 Tests de validación (agregados 2026-11-12)

### Qué prueba realmente el test actual (∇g = 0)
Si Γ se arma con la fórmula de Levi-Civita y g⁻¹ es la inversa exacta de g, entonces
Γ_{νσμ} + Γ_{μσν} = ∂_σ g_{μν}, y ∇g = 0 se cumple **para cualquier g simétrica**.
- ✅ Prueba: `metric_inverse` es la inversa de `metric` (escritas por separado), las convenciones de
  índices de `_Γcomp` / `Γ[μ,ν,λ]` y la maquinaria Dual.
- ❌ No prueba: que `metric` sea Kerr (un error físico coherente en g y g⁻¹ pasa) ni que las derivadas
  sean correctas (el test calcula ∂g con el mismo seeding de Duals que `christoffel`).

### 17. AD vs diferencias finitas (objetivo: AD)
∂_σ g_{μν} ≈ [g(x + h e_σ) − g(x − h e_σ)] / 2h, armar Γ con la misma fórmula y comparar con
`christoffel(st, x)`. Float64, h ~ 1e-6·|x|, rtol ~ 1e-7.

### 18. Vector nulo (objetivo: métrica)
`_H_l` devuelve l_μ. Verificar η^{μν} l_μ l_ν = 0, g^{μν} l_μ l_ν = 0 y g_{μν} lᵘ lᵛ = 0.

### 19. Límite a = 0 (objetivo: métrica)
Schwarzschild en Kerr-Schild: r = |x⃗|, 2H = 2M/r, l = (1, x/r, y/r, z/r), g = η + 2H l l.
Comparar con `metric(KerrSchildCoordinates(M=1.0, a=0.0), x)`.

### 20. Ricci = 0 (objetivo: métrica + AD de segundo orden)
R_{μν} = ∂_λΓ^λ_{μν} − ∂_νΓ^λ_{μλ} + Γ^λ_{λσ}Γ^σ_{μν} − Γ^λ_{νσ}Γ^σ_{μλ}.
∂Γ con Dual anidado (outer tag distinto de `ChristoffelTag`) o con diferencias finitas de `christoffel`.

### 21. Constantes de movimiento (cadena completa)
A lo largo de una geodésica integrada: g_{μν}kᵘkᵛ = 0, E = −k_t, L_z = x k_y − y k_x (índices bajos),
constante de Carter. Requiere #2 y la propagación funcionando.

Para todos: varios puntos (incluido r < r₊ y cerca del eje), y Float32 con tolerancias más laxas.
Nota: la constante de Carter no es genérica (tensor de Killing de Kerr) → método de `AbstractKerrSpacetime`.

## 🧭 Capa geométrica genérica (principio de diseño, 2026-11-13) — ⛔ DESCARTADO

> Decisión 2026-11-13: no se implementa este plan. Cada magnitud se agregará a pedido siguiendo el
> patrón de `christoffel` (función genérica de `(spacetime, x)` con `metric`, `metric_inverse` y Duales).
> Se conserva abajo solo como referencia histórica.

**Objetivo del usuario:** todo (radio/horizonte, frecuencias, conservadas, callbacks...) se calcula en
términos de la métrica, su inversa y derivadas vía Duales. Una métrica nueva solo define
struct (+ `topology`), `metric`, `metric_inverse` y `numtype`. Distinción opcional por simetría
(axial / esférica) para simplificar, siempre genérica.

**Idea clave:** usar invariantes construidos con g y vectores de Killing → independientes de coordenadas
(sirven igual en Kerr-Schild y Boyer-Lindquist).

### 24. Horizonte, ergosfera, callback
```julia
@inline gdot(g, u, v) = u' * g * v
@inline function lapse2(st::AbstractStationaryAxisymmetric, x)
    g  = metric(st, x)
    ξt = killing_t(st.topology, x);  ξφ = killing_φ(st.topology, x)
    gtt, gtφ, gφφ = gdot(g, ξt, ξt), gdot(g, ξt, ξφ), gdot(g, ξφ, ξφ)
    return ifelse(gφφ > eps(gφφ), -(gtt - gtφ^2 / gφφ), -gtt)   # eje: límite exacto -gtt
end
@inline lapse2(st::AbstractStaticSpherical, x) =
    -gdot(metric(st, x), killing_t(st.topology, x), killing_t(st.topology, x))
ergosphere(st, x) = gdot(metric(st, x), killing_t(st.topology, x), killing_t(st.topology, x))
capture_condition(u, t, integrator) = lapse2(integrator.p.spacetime, SVector(u[1], u[2], u[3], u[4])) - ε
```

En BL Γ diverge en el horizonte → usar umbral ε > 0.
